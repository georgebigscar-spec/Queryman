# Шрифты

Положите сюда файлы и соберите с `--features bundled-fonts`:

- `Inter-Regular.ttf` — интерфейс (https://rsms.me/inter/, OFL)
- `JetBrainsMono-Regular.ttf` — код и тела запросов (https://www.jetbrains.com/lp/mono/, OFL)

Без этой feature используется встроенный шрифт egui: у него нет жирного начертания.
